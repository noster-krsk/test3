# Мини-синхронизатор заявок

Забирает сырые заявки с `https://test.ooobs.ru/api/orders`, нормализует телефоны, дедуплицирует по телефону и отдаёт результат.

**Живой URL:** https://test3.one-vpn.ru/result/

## Правила
- Телефон: из строки берутся только цифры; валиден, если их ровно 11 и первая `7` или `8`, либо ровно 10 и первая `9` (мобильный без кода страны, дописывается `7`) → `+7XXXXXXXXXX`. Остальное (`123`, `""`, `не указан`, `+7 999`, 10 цифр не с `9`) отбрасывается и считается в `invalid_dropped`.
- Дубли по телефону: остаётся запись с максимальным `amount`, при равенстве — с более поздним `created_at` (последний тай-брейк — больший `id`, чтобы результат был детерминированным). Поля берутся из выигравшей записи целиком, без склейки.
- `duplicates_merged = валидных − уникальных`, `received = unique + duplicates_merged + invalid_dropped`.
- Порядок клиентов — по первому появлению телефона в источнике.

## Идемпотентность
Каждый запрос к `/result/` запускает синхронизацию: снимок источника в одной транзакции заменяет хранимый в SQLite (`phone` — PRIMARY KEY), поэтому повторные запуски дают тот же результат и не могут породить дубли. Если источник недоступен, отдаётся последний сохранённый результат.

## Стек и структура
PHP 8.3 (без зависимостей, curl + PDO SQLite), nginx + php-fpm на своём сервере.
- `src/Sync.php` — нормализация, дедупликация, хранение
- `src/bootstrap.php` — конфигурация
- `result/index.php` — HTTP-эндпоинт
- `tests/run.php` — тесты: `php tests/run.php`

## Секреты и конфигурация
Источник публичный, токенов не требуется. Конфигурация (`SOURCE_URL`, `DB_PATH`) читается из переменных окружения или из `private/.env` вне webroot; в репозитории только безопасные дефолты, `.env` и база в `.gitignore`. Деплой-ключ для GitHub лежит в `~/.ssh` сервера.
